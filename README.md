# Segundo-parcial

### Rama: `feature/plusval-scraper`

Esta rama fue creada para desarrollar e integrar el scraper de **Plusval** al proyecto inmobiliario de República Dominicana.

Su objetivo fue automatizar la extracción de **200 propiedades**, obteniendo información como nombre, precio, ubicación, vendedor, tamaño, habitaciones, baños y parqueos.

Se utilizaron **Python, Requests y BeautifulSoup**, aplicando funciones y programación orientada a objetos. Además, se integró el scraper con el sistema principal para procesar los datos mediante **pandas**, registrar los tiempos de las solicitudes HTTP y generar reportes en **Excel, Parquet, HTML y JSON**.

Una vez completado y probado su funcionamiento, los cambios fueron fusionados con la rama `main` del proyecto.
